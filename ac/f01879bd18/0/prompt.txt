You're not missing anything. Lock Code Manager records the information, but Home Assistant doesn't show it in either place you looked.



**Why the lock says "No cause was recorded":** that field only gets filled when something inside Home Assistant caused the change, like an automation or a button you pressed in the UI. A keypad or fingerprint unlock happens on the lock itself. The lock integration reports the new state, and Lock Code Manager hears separately which user it was. Lock Code Manager can't attach that to the lock's state change, so that line will keep saying it.



**What's coming in the next release:**

- **Each use goes into the logbook of the lock it was used on.** Open Front Door Lock's activity (or the Logbook page, filtered to that lock) and you'll see "Alice used a PIN to unlock" right next to the "Unlocked" entry. Card readers, fingerprint and face recognition show up the same way on locks that report which kind was used.

- **Clicking "Last used" on the user card lists their recent uses.** Each one shows which lock, what kind of credential and whether it locked or unlocked, plus when. A "Full history" link underneath opens the complete history.
